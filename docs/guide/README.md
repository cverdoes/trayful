| [Playing with others](play-with-others.md)       | Invite playtesters over your network or a tunnel, with private hands  |
| [Let an agent play](agents.md)                   | Connect Claude or another MCP client to play and build with you       |
| [Make your own prototype](your-own-prototype.md) | The project folder, the designer, live reload and what components are |
