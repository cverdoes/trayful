# Trayful documentation

- [HOWTO guides](howto/README.md): short task guides, such as starting a project, adding a deck of cards, loading cards from a spreadsheet, adding a board with drop areas, using tiled images, or designing components with an agent. Start here.
- [Format reference](reference/README.md): every file kind and key, generated from the schemas so it always matches what Trayful accepts, plus pages on units, faces and templates, snapping, validation errors and versioning (including moving a `trayful/1` project to `trayful/2`).

Agents connected over MCP read these same pages as the `trayful://docs` resource. The files quoted in the guides come from [`examples/`](../examples), and a test checks that they match, so the guides stay true.
