# Trayful documentation

- [HOWTO guides](howto/README.md): short task guides, such as starting a project, adding a deck of cards, loading cards from a spreadsheet, adding a board with snap spots, or designing components with an agent. Start here.
- [Format reference](reference/README.md): every file kind and key, generated from the schemas so it always matches what Trayful accepts, plus pages on units, faces and templates, snapping, validation errors and versioning.

Agents connected over MCP read these same pages as the `trayful://docs` resource. The files quoted in the guides come from [`examples/`](../examples), and a test checks that they match, so the guides stay true.
