# Trayful documentation

- [Format reference](reference/README.md): every file kind and key, generated from the schemas so it always matches what Trayful accepts.
- HOWTO guides (Milestone 4): short task guides such as adding a deck of cards, loading cards from a spreadsheet, or adding a board with snap spots. Until then, the [Harvest Moon example](../examples/harvest-moon) shows each file kind in use.
